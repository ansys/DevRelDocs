# SensorOptions

## Description

Represents the options of a sensor.

## Member Summary

| Member | Type | Description |
| --- | --- | --- |
| [LightExpert](#lightexpert) | public | Gets or sets the property Light Expert. |

## Public Static Attributes

### LightExpert

`bool LightExpert`

Gets or sets the property Light Expert.

True: Enables the Light Expert option for the sensor.  
False: Disables the Light Expert option for the sensor.  
  
**Value type**: Boolean.  
  
The default value is False.
