# GeometryOptions

## Description

## Public Static Attributes

### FastTransmissionGathering

`bool FastTransmissionGathering`

Gets or sets the property Fast Transmission Gathering.

True: Enables the Fast Transmission Gathering option for the geometry.  
False: Disables the Fast Transmission Gathering option for the geometry.  
  
**Value type**: Boolean.  
  
The default value is False.
