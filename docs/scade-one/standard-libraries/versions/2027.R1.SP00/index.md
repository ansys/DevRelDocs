# Introduction

Scade One provides a collection of libraries for model development, simulation and debugging.

|Library|Description|
|-------|-----------|
|[Bitfield](libraries/bitfield/bitfield.md)|Bit-level operations and conversions.|
|[Check](libraries/check/check.md)|Operators for building test oracles.|
|[Control::Common](libraries/control_common/control_common.md)|Common control operators.|
|[Control::Discontinuous](libraries/control_discontinuous/control_discontinuous.md)|Discontinuous control operators.|
|[Control::Filters](libraries/control_filters/control_filters.md)|Filters and signal-processing operators.|
|[Digital](libraries/digital/digital.md)|Basic functions for digital data processing.|
|[Float](libraries/float/float.md)|Floating-point utilities and operations.|
|[Flows](libraries/flows/flows.md)|Flow operators, including delays, counters, and timers.|
|[Math::Common](libraries/math_common/math_common.md)|Common mathematical operations.|
|[Math::Complex](libraries/math_complex/math_complex.md)|Complex number types and operations.|
|[Math::Trigo](libraries/math_trigo/math_trigo.md)|Trigonometric functions and their inverse.|
|[Matrix](libraries/matrix/matrix.md)|Matrix operations.|
|[Sources::N](libraries/sources/sources_n.md)|Cycle-based flow generators.|
|[Sources::T](libraries/sources/sources_t.md)|Time-based flow generators.|
|[Vector](libraries/vector/vector.md)|Vector operations.|

**Note:** Abbreviations:

-   I: Input variable
-   O: Output variable
-   P: Size parameter
