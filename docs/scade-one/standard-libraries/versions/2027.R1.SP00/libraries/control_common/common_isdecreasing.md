# IsDecreasing {#common_isdecreasing .sone-topic}

Returns whether the input flow is decreasing.

## Interface { .section}

|Name|Kind|Type|Comment|
|----|:--:|----|-------|
|signal|I|numeric|Input flow|
|strict|I|bool|A stable flow is considered as decreasing when strict is false.<br> Default: false|
|check|O|bool|Whether the flow is decreasing|
