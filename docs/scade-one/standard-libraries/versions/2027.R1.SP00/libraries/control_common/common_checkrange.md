# CheckRange {#common_checkrange .sone-topic}

Returns whether a value is within an interval.

This corresponds to the operator [Bounds](../check/check__bounds.md) from the Check library.

## Interface { .section}

|Name|Kind|Type|Comment|
|----|:--:|----|-------|
|input|I|numeric|Input value|
|min|I|numeric|The minimum value of the range|
|max|I|numeric|The maximum value of the range|
|check|O|bool|Whether input is within min and max|
