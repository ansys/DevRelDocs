# IsIncreasing {#common_isincreasing .sone-topic}

Returns whether the input flow is increasing.

## Interface { .section}

|Name|Kind|Type|Comment|
|----|:--:|----|-------|
|signal|I|numeric|Input signal|
|strict|I|bool|A stable flow is considered as increasing when strict is false.<br>Default: false|
|check|O|bool|Whether the flow is increasing|
