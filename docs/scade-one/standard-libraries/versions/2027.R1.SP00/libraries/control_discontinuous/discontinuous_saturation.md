# Saturation {#discontinuous_saturation .sone-topic}

Bounds the input signal between min and max.

## Interface { .section}

|Name|Kind|Type|Comment|
|----|:--:|----|-------|
|x|I|numeric|Input signal|
|min|I|numeric|Minimum saturation limit|
|max|I|numeric|Maximum saturation limit|
|y|O|numeric|Output signal|
|saturation|O|bool|Saturation flag|
