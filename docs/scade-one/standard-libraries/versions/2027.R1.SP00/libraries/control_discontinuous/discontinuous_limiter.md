# Limiter {#discontinuous_limiter .sone-topic}

Bounds the input between the lower and upper limit.

## Interface { .section}

|Name|Kind|Type|Comment|
|----|:--:|----|-------|
|input|I|numeric|Input signal|
|upperlimit|I|numeric|Upper Limit|
|lowerlimit|I|numeric|Lower Limit|
|output|O|numeric|Output signal|
