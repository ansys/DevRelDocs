# Hysteresis {#discontinuous_hysteresis .sone-topic}

Switches the output at separate rising and falling thresholds, retaining its state between them.

## Interface { .section}

|Name|Kind|Type|Comment|
|----|:--:|----|-------|
|x|I|numeric|Input signal|
|sp|I|numeric|Set point \(upper threshold\)|
|rx|I|numeric|Reset point \(lower threshold\)|
|y|O|numeric|Output signal|
