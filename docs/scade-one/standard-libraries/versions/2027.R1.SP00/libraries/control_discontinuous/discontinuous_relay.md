# Relay {#discontinuous_relay .sone-topic}

Implements a relay that switches between two values.

## Interface { .section}

|Name|Kind|Type|Comment|
|----|:--:|----|-------|
|x|I|numeric|Input signal|
|upperlimit|I|numeric|Upper limit of the switch|
|lowerlimit|I|numeric|Lower limit of the switch|
|valueon|I|numeric|Value when the switch is on|
|valueoff|I|numeric|Value when the switch is off|
|y|O|numeric|Output signal|
