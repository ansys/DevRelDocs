# Control::Discontinuous {#control_discontinuous .sone-topic}

Discontinuous control operators.

|Operator Name|Description|
|-------------|-----------|
|[DeadBand](discontinuous_deadband.md)|Reduces the signal output to the offset value when the signal is within the deadband.|
|[Saturation](discontinuous_saturation.md)|Bounds the input signal between min and max.|
|[Hysteresis](discontinuous_hysteresis.md)|Switches the output at separate rising and falling thresholds, retaining its state between them.|
|[RateLimiter](discontinuous_ratelimiter.md)|Limits the rate of change of the signal passing through to the specified limit.|
|[Relay](discontinuous_relay.md)|Implements a relay that switches between two values.|
|[Limiter](discontinuous_limiter.md)|Bounds the input between the lower and upper limit.|
