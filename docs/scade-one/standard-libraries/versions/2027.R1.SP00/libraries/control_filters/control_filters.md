# Control::Filters {#control_filters .sone-topic}

Filters and signal-processing operators.

|Operator Name|Description|
|-------------|-----------|
|[Lag](filters_lag.md)|Adds a lag to the phase response of the input signal.|
|[LowPass](filters_lowpass.md)|Attenuates the input signal if its frequency is greater than the chosen cut-off frequency.|
|[HighPass](filters_highpass.md)|Attenuates the input signal if its frequency is lower than the chosen cut-off frequency.|
|[BandPass](filters_bandpass.md)|Attenuates the input signal if its frequency is outside the chosen frequency band.|
|[BandStop](filters_bandstop.md)|Attenuates the input signal if its frequency is within the chosen frequency band.|
|[DigitalFilter](filters_digitalfilter.md)|Implements a digital filter.|
|[BiQuad](filters_biquad.md)|Second-order recursive filter.|
|[SecondOrderSeries](filters_secondorderseries.md)|Cascaded second-order structure sections filter.|
