#### *class* Ansys.Mechanical.Graphics.Labels.PointProbeScoping

Bases: [`object`](https://docs.python.org/3/builtins/functions.html#object)

This class defines a 3D-point based probe label scoping.
The scoping performs a hit detect on the pre-solve mesh and if it intersects,
will track that hitpoint's position and result value.
