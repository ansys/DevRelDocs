#### *class* Ansys.Mechanical.DataModel.Enums.LegendIndependentBandsType(\*args, \*\*kwds)

Bases: [`enum.Enum`](https://docs.python.org/3/library/enum.html#enum.Enum)

Specifies the legend bands types rendered independently of the main scale.

Unlike standard bands that blend or transition smoothly,
independent bands maintain hard boundaries between the rest
of the bands to ensure they remain distinct.
