# Introduction

The `ansys-mechanical-stubs` package provides Python type hints for Mechanical scripting and is
installed automatically with PyMechanical. This reference describes Mechanical objects, methods,
and properties across its namespaces. It is intended for Python developers using PyMechanical with
Ansys Mechanical. For supported Python versions, operating systems, and Mechanical installation
requirements, see the [PyMechanical installation guide](https://mechanical.docs.pyansys.com/version/stable/getting_started/installation.html).

Autocomplete is supported in VS Code. See the [Autocomplete guide](https://mechanical.docs.pyansys.com/version/stable/user_guide/embedding/autocomplete.html),
or run `ansys-mechanical-ideconfig` to configure VS Code settings automatically. See the [CLI reference](https://mechanical.docs.pyansys.com/version/stable/user_guide/cli/ansys-mechanical-ideconfig.html)
for command details.

For practical examples, see the [Scripting in Mechanical Guide](https://ansyshelp.ansys.com/public/account/secured?returnurl=/Views/Secured/corp/v271/en/act_script/act_script.html).
The [ACT API Reference Guide](https://ansyshelp.ansys.com/public/account/secured?returnurl=/Views/Secured/corp/v271/en/act_ref/act_ref.html)
lists all supported APIs; this documentation provides a focused subset for Mechanical:

- [API reference](api/index.md)
