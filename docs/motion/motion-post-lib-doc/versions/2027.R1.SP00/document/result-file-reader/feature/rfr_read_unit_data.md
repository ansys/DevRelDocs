# Read Unit Data
This feature covers reading result-unit names and scale factors with [`OutputReader`](../../../lib/VM.Post.API.OutputReader.OutputReader.md).

## Result Units
Read the unit and conversion factor for each result dimension with [`GetUnits()`](../../../lib/VM.Post.API.OutputReader.OutputReader.GetUnits.md).

## Mode-Shape Units
Read unit information stored in a modal body's mode-shape file with [`GetUnitsFromModeShapeFile(string)`](../../../lib/VM.Post.API.OutputReader.OutputReader.GetUnitsFromModeShapeFile.md).
