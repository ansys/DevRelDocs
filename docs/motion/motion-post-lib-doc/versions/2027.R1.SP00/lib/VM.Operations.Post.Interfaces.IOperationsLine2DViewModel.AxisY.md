## <a id="VM_Operations_Post_Interfaces_IOperationsLine2DViewModel_AxisY"></a> AxisY

Gets or sets whether the Y axis is rendered in the 2D chart. `true` renders the axis and `false` hides it.

```csharp
bool AxisY { get; set; }
```

### Property Value

 bool

### Remarks

Changing this value updates the chart axis visibility without changing curve data.
