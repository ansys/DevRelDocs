## <a id="VM_Operations_Post_Interfaces_IOperationsLegendModifier_ItemsInFilter"></a> ItemsInFilter

Gets or sets whether the legend displays all chart curves or only visible curves, using the `All Curves` or `Visible Curves` filter label.

```csharp
string ItemsInFilter { get; set; }
```

### Property Value

 string

### Remarks

Changing this value updates the set of curve entries represented in the legend.
