# Creating add-in applications

This guide documents Discovery's .NET extensibility API and includes examples for creating add-ins that extend Discovery. An add-in is a managed assembly loaded by Discovery using a manifest. The examples target the V271 assemblies for 2027 R1; see [API versions](../../../../index.md#api-versions) for the release mapping and upgrade guidance.

This document contains information on the following:

-   The basic infrastructure for add-in customization.
-   How to add custom elements to the User Interface.
-   An overview of the geometry architecture.
