# Version 2027 R1

**Version 2027 R1 (V271)** introduces significant API changes focused on improving consistency, clarity, and separation of concerns across the Discovery API. Key updates include broader use of explicit Simulation context, relocation of user interface functionality to dedicated namespaces, enhancements to material, fan, and topology optimization workflows, and numerous API renaming, refactoring, and deprecation changes. Users upgrading from V261 should review and update existing scripts and compiled add-ins to accommodate these breaking changes.

## Simulation is now required

- `Simulation` is no longer optional on most API methods. For most `Create` methods it has also moved to the first parameter. (PRs 662857, 665811, 666487, 667170, 668688, 669394, 670681)
  - The old `Create(ISelection …, Simulation simulation = null)` overloads were removed. Use `Create(simulation, selection, …)` instead. Affected types:
    - `Acceleration`, `BearingLoad`, `BoltPreload`, `Contact`, `Convection`, `Current`, `Voltage`
    - `Displacement`, `Flow`, `Force`, `Heat`, `InsulatedCondition`, `Joint`, `Mass`, `Moment`
    - `Porous`, `Pressure`, `RotatingFluidZone`, `Support`, `Symmetry`, `Temperature`, `Velocity`, `Wall`
    - `BeamAssignment`, `MaterialAssignment`
  - `Simulation` keeps its position but is no longer optional:
    - `CircuitPort.Create`, `ModePort.Create`, `Spring.Create`, `LocalFidelity.Create`, `FilletWeld.Create`
    - `Monitor.Create`, `LineChart.Create`, `PowerSpectralDensityChart.Create`, `MaterialParameter.Create`
  - `Simulation` moved to the first parameter: `Chart.Create`, `MeshSessionHelper.MeshSimulation`
  - Other members that now require `Simulation`:
    - `GetByLabel` on `BeamAssignment`, `BoltAssignment`, `MaterialAssignment` and `ModalSettings`
    - `BeamAssignment.Extract`
    - `Monitor.ClearAll`, `Monitor.ClearCurrent`, `Monitor.ExportChart`, `Monitor.ExportDetailedChart`, `Monitor.ExportAllCharts`, `Monitor.ExportConnectionAssessmentDataToCsv`
    - `GetDataSeries` and `ExportData` on `Chart`, `LineChart` and `PowerSpectralDensityChart`
    - `Fidelity.AutoDetect`
    - `SubdivisionSurfaces.ConvertToSubDHybrid`
    - `Commands.CreateVirtualWall`, `Commands.ExcludeFromInterfaceDetection`
    - `MaterialExtensionsHelper.GetMaterial`
    - `Material.AdjustMaterialAssignments`, `Material.GetByLabel`
    - `ScriptParameter.Create`
    - `Solver.SolveConfidence`

## Members moved to the UserInterface API

- These members moved from `Discovery.Api.V271` to `Discovery.Api.V271.UserInterface`. (PRs 662857, 664323)
  - `Simulation.SetCurrentSimulation`. `Simulation.GetCurrentSimulation` stays in the API but is marked obsolete.
  - `Solver.StartExplore`, `Solver.StartRefine`, `Solver.PauseExplore`
  - `ApplicationEvents.SimulationChanged`, `ApplicationEvents.StageChanged`

## Simulation material methods

- These methods changed from static to instance methods. (PR 682279)
  - `Simulation.AssignMaterial`
  - `Simulation.RemoveMaterialAssignment`
  - `Simulation.GetDefaultMaterialAssignments`

## Materials

- `Material.GetProjectMaterial(name)` now needs either a `MaterialSource` or a `Simulation` argument. (PR 680229)

## Contacts

- The `ContactGroup.ChangeType` overloads that took an `ISelection` or `Simulation` were removed. (PR 662544)

## File

- In `File.ExportTableToFile`, the `int tableExportFormat` parameter is now the `TableExportFormat` enum. (PR 722577)
- UserInterface `File.Save` changed. (PR 733270)
  - Before: `Save(withoutRefineResult, withoutExploreResult, useNewVersion)`
  - After: `Save(withoutResult, useNewVersion)` (obsolete) and `Save(FileSaveOptions)`
  - Calls with three arguments no longer work.
  - Calls with two positional arguments still run but do something different. For example, `Save(False, True)` used to mean "without Explore results" and now means "new version".

## Fans (unified fans)

- Old fan types were removed and replaced. (PRs 691826, 693875)
  - Removed: `Fan`, `FanDefinition`, `InternalFan`, `InternalFanDefinition`
  - Removed: the `InternalFanSource` and `InternalFanSpecification` enums
  - Replacements: `FanAssignment` (for example, `FanAssignment.CreateBoundaryFan`) and `FanModel`
  - `DiscoveryTesting.ValidateFan` and `DiscoveryTesting.ValidateInternalFan` were removed.

## Topology optimization

- `ReductionOption.ReduceByVolume` was renamed to `ReductionOption.TargetVolume`. (PR 685854)
  - New values: `TargetMass`, `ReduceByMassPercent`
- `TopologyOptimization` behaviour changes. (PR 726763)
  - Constraint getters now return `null` instead of throwing `InvalidOperationException` when the constraint isn't defined.
  - The `ReductionOption` getter can now return the new mass-based options instead of throwing `NotSupportedException`.

## Namespace changes

- `ShareTopologyReview` and `ShareTopologyReviewInfo` moved from `Ansys.Discovery.Api.V271.Scripting.Extensions` to `Ansys.Discovery.Api.V271.ShareTopology`. (PR 733675)

## Custom wrappers

- `PhysicsCustomWrapper.Apply()` was removed. (PR 662857)

## UserInterface: ResultsProvider

- `ResultsProvider` methods now require `Simulation`. (PR 662857)
  - `RegisterMesh` and `RegisterFarFieldMesh`: `Simulation` is now required and comes before `activate`.
  - `SetReferenceLength`
  - `SetAnimationDuration`
  - `SetAnimationGlobalMinMaxValue`
  - `UpdateAnimationSaveStatus`

## UserInterface: Custom UI XML

- The `CT_Tab` attribute `DefaultForStage` was renamed to `DefaultStage`, which matches the XSD. Ribbon XML that used `DefaultForStage` with V261 needs updating. (PR 685514)

## Compiled C# add-ins only (scripts unaffected)

- These changes don't affect scripts, but compiled add-ins built against V261 must be recompiled.
  - `MaterialAssignment.Create` now returns `MaterialAssignment` instead of `void`. (PR 667871)
  - `DefinedVariationTable.AddPhysicsParameter`, `AddMaterialParameter` and `RemovePhysicsParameter` now take `Parameter` instead of the more specific parameter types.
  - The `DiscoveryCustomWrapper` constructor has a new optional `persist` parameter. (PR 689042)
  - `Simulation.DuplicateSimulation` has a new optional `includeOnlyMaterials` parameter. (PR 708492)
