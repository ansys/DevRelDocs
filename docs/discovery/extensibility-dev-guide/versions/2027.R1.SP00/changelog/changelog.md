# Changelog

The following summaries highlight changes documented for each release. See the linked release page for details.

## 2027 R1

- **Changed:** Many APIs now require an explicit `Simulation`; UI members moved to dedicated namespaces; fan and topology optimization APIs changed. Compiled add-ins built against V261 must be updated and recompiled. ([Full changelog](./V27-r1.md))

## 2026 R1

- **Added:** Stage-definition parameterization delegates and custom-tree highlighting support.
- **Changed:** Contact and interface properties and DetectTool naming were updated. ([Full changelog](./V26-r1.md))

## 2025 R2

- **Added:** Custom-tree controls, mesh registration methods, and internal-fan volume-flow curve support.
- **Changed:** Material assignments, result-variable names, and UI/API organization were updated. ([Full changelog](./V25-r2.md))

## 2025 R1

- **Added:** Custom-tree, material, ribbon, and physics API capabilities.
- **Changed:** Application event and menu namespaces were reorganized.
- **Deprecated:** API V22. ([Full changelog](./V25-r1.md))

## 2024 R2

- **Added:** Custom-tree and variation-table API capabilities, HUD validation and read-only options, theme access, and VTU export.
- **Changed:** Custom-tree performance and selection synchronization improved; API names and namespaces were updated. ([Full changelog](./V24-r2.md))
