# PyAnsys learning roadmaps

These roadmaps are capability-based guides to learning the PyAnsys libraries. They measure what you can *do*, and not how many pages you have read. Each one breaks the journey into progressive stages, from installing the library and running your first session through to modifying real workflows, building reusable automation, applying them to your own use cases, and using AI-assisted capabilities such as each library's Model Context Protocol (MCP) server.

## Goals

- **Build real capability** — every milestone leaves you able to do something you could not do before.
- **Get working fast** — reach a running session and a first result early, then build on it.
- **Produce reusable artefacts** — finish each step with a script, result, or note worth keeping.
- **Ground everything in official sources** — worked examples are drawn from the library's own documentation.
- **Use AI responsibly** — apply AI-assisted capabilities while verifying every generated result against the solver or tool.

## How they work

- **Progressive stages** — ordered from first install through to advanced, AI-assisted, and specialised workflows.
- **Capability milestones** — each milestone is a concrete, demonstrable capability.
- **A consistent structure** — every milestone gives you an *activity*, a worked *example*, an observable *complete when* check, and an artefact to *keep*.
- **Flexible paths** — follow the stages in order for the shortest route to competence, or jump straight to the capability you need.
