# Introduction

The ModelCenter Remote Execution Python ScriptWrapper API provides runtime services for Script Wrapper components in ModelCenter Remote Execution (MCRE) 2027 R1. Use this API when authoring Python Script Wrappers that define variables, handle file I/O, and participate in run-share monitoring.

For setup guidance and your first wrapper script, see [Getting started](started.md). For class and method details, see the [Python API reference](modelcenter-python-api.md).

For Script Wrapper authoring concepts and deployment, see the [MCRE ScriptWrapper documentation](https://ansyshelp.ansys.com/public/account/secured?returnurl=/Views/Secured/ModelCenter/v271/en/ModelCenter_Rem_Exec/ModelCenter_Rem_Exec/mcre_functions/wrappers_components/ScriptWrapper/index_scriptWrapper.html).

## Who should use this API?

- Python developers authoring Script Wrapper components for MCRE
- Teams extending MCRE workflows with custom Python logic
- Integrators who need the `wrapper` global object and related variable types

## Supported environment

- **Language:** Python (Script Wrapper runtime supplied by MCRE)
- **Platform:** Windows (ModelCenter Remote Execution installation required)
