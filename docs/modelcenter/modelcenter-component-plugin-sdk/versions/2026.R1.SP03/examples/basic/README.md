# BasicPaczPlugin sample

Bundled copy of the Ansys `pacz-component-plugins` BasicPaczPlugin example for the Getting started walkthrough in `started.md`.

- Prefer naming a VSIX-created project `BasicPaczPlugin` so you can copy these sources with fewer namespace edits.
- Point NuGet at your unzipped `PACZComponentPlugInSDK-*` folder. This `.csproj` targets `Phoenix.ComponentPlugInSDK` **26.1.1**; change the version if your SDK differs.
