# Introduction

The ModelCenter API documentation for **2027 R1** describes programmatic access to ModelCenter through COM automation and Java bindings. Use these APIs to automate workflows, integrate external tools, extend ModelCenter with custom plug-ins, and connect to analyses across your engineering environment.

The ModelCenter API empowers you to easily perform important tasks, including:

- Automate and optimize complex, cross-disciplinary engineering workflows.
- Integrate simulations and tools from various domains.
- Extend functionality through custom plugins.
- Use ModelCenter results and models for advanced postprocessing and analysis.
- Remotely connect to any engineering analysis and workflows stored anywhere in the world while securing the IP.

## Who should use this API?

- Developers building automation scripts or integrations with ModelCenter
- Engineering teams connecting proprietary tools to ModelCenter workflows
- Plug-in and algorithm authors extending ModelCenter functionality

## Supported languages and platforms

- **COM API:** Accessible from any COM-capable language on Windows (for example, Python, MATLAB, C#, VBScript)
- **Java API:** Java applications on Windows with ModelCenter Java API JARs on the classpath
- **Platform:** Windows (ModelCenter desktop installation required)

For setup guidance, see [Getting started](getting-started.md).
