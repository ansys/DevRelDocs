# Examples

To assist with creating a plugin for a third-party or in-house application, the following examples are provided.

* [Server-based plugin - Material Logger](example-server-material-logger.md): A C# plugin for the MI Integration Service that logs materials data to a text file, demonstrating the `IPlugin`/`IPluginFactory` interfaces used by server-based integrations.
* [Desktop-based plugin - C#](example-desktop-csharp.md): A C# console application demonstrating the end-to-end desktop integration flow, using the MI Integration Service REST API and Server-Sent Events.
* [Desktop-based plugin - Python](example-desktop-python.md): A Python script demonstrating the end-to-end desktop integration flow, using the MI Integration Service REST API and long-polling.
