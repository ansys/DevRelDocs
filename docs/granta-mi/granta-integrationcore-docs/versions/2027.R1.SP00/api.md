# API Reference

Granta MI Materials Gateway exposes two APIs for developers writing custom integrations:

- **[MI Integration Service](xref:MI%20Integration%20Service/1.1.0)**: A REST API over HTTPS for integrating materials data into host applications. Use this API to query and retrieve Granta MI data from your host application.
- **[Server Plugin](xref:Ansys.GrantaMI.IntegrationCore.ServerPlugin.V1)**: A .NET API for writing server-based plugins that extend the Integration Service, for example to add custom material data sources or exporters.
