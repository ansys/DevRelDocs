# Introduction

MI Materials Gateway enables data and tools to be accessed directly from within CAD, CAE, or PLM applications.
You can access the Granta database system, choose materials, and assign or import those materials to your design or simulation model.

The Granta MI Integration Development Kit is provided to help you write custom MI Materials Gateway integrations for host applications that are not supported out-of-the-box.

A custom integration provides the ability to search and browse Granta data, and import materials into a host application in the format that application requires.

Materials can be imported either as material references with traceability data,
or as material cards with the format and properties specified by a material card exporter (for example, material models for a CAE analysis package).
