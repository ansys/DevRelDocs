# Style Guidance

Resources to achieve a consistent look and feel when integrating MI Materials Gateway into your application.

## Names and Acronyms

The name of the product is **Granta MI Materials Gateway**.

## User Interface Terminology

When adding controls to launch MI Materials Gateway, use the following text for buttons, menu items, and tooltips:

| Location  |  Text |
|---|---|
| Button label  | Granta MI  |
| Menu label  | Import materials from Granta MI  |
| Tooltip | Import Granta Materials into your project  |
| Embedded browser dialog header/ Browser  | Granta MI Materials Gateway |

## Icons

All icons are available in all Ansys Design Language themes, and provided in standard sizes as `.bmp` and `.png` files in [Granta_Materials_icons.zip](resources/Granta_Materials_icons.zip)
