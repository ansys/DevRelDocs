<a id="functionality-deprecated-with-version-5-0"></a>

## Functionality deprecated with version 5.0

#### Table 2: Functionality deprecated with version 5.0

| Deprecated functionality                              | Recommended replacement / future functionality                               |
|-------------------------------------------------------|------------------------------------------------------------------------------|
| Installing `GRANTA_MIScriptingToolkit`                | Install `ansys-grantami-core` or `ansys-grantami-backend-soap`               |
| `from GRANTA_MIScriptingToolkit import granta as mpy` | Import the streamlined layer with `import ansys.grantami.core as mpy`        |
| `import GRANTA_MIScriptingToolkit as gdl`             | Import the foundation layer with `import ansys.grantami.backend.soap as gdl` |
